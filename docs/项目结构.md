> 更新日期：2026-08-03
>
> 文档性质：当前仓库目录与逐文件职责索引，不代表尚未落地的目标架构。

## 1. 使用说明

- 本文描述当前工作区中由项目维护的文件。产品边界以《产品路线图》为准，目标模块和依赖方向以《技术架构》为准。
- 新增、删除、重命名文件或改变文件主要职责时，必须同步更新本文。
- 源码文件指项目维护的 `.swift`、`.mjs` 和 `.sh` 文件。每个源码文件顶部使用“功能 / 职责 / 边界”三行注释；Shell 脚本的 shebang 必须保留在第一行。详细规则见《编程 Agent 规范》。
- `DerivedData/`、`Backend/.data/`、`xcuserdata/`、`.DS_Store` 和覆盖率输出属于本地产物，不是源码，也不应作为实现事实的依据。

## 3. macOS App

### 3.1 入口与主界面

| 文件 | 作用与功能 |
| --- | --- |
| `Friday/FridayApp.swift` | App 入口和应用级状态容器；创建常驻顶部灵动岛，并在组合根装配 Dictate、Direct Realtime Talk Runtime、权限、快捷键、应用意图解析与本地 Action 工作流。 |
| `Friday/ContentView.swift` | 灵动岛展开矩形的主页与设置菜单；集中展示快捷操作、服务、权限、用量、提示、最近结果和通用命令。 |
| `Friday/Info.plist` | App Bundle 元数据、macOS 14.0 最低版本、后台 UIElement 模式、本地网络以及麦克风和屏幕录制权限说明。 |

`FridayApp.swift` 和 `ContentView.swift` 目前仍位于 App 源码根目录。目标架构中的 `App/` 迁移尚未发生，不能仅为了目录外观移动它们。

### 3.2 Core

| 文件 | 作用与功能 |
| --- | --- |
| `Friday/Core/ConversationProvider.swift` | 定义 Talk 状态、事件、图片上下文、Provider 协议、模式、限制、价格估算、提示词和零成本 Mock。 |
| `Friday/Core/DictationPrompt.swift` | 定义单轮听写整理提示词与输出防护，处理无语音、确认包装、代码围栏和原始转写回退。 |
| `Friday/Core/DictationProvider.swift` | 定义听写音频、上下文、结果、用量和 Provider 协议，并提供零成本 Mock 实现。 |
| `Friday/Core/DictationWorkflowState.swift` | 定义 Dictate 模式、恢复动作、错误和从就绪检查到成功或可恢复失败的统一状态机。 |
| `Friday/Core/RealtimeConversationProvider.swift` | 实现 Talk 的 Realtime WebSocket 客户端；管理短期凭证、PCM16 上传、音频输出、图片上下文和事件解析。 |
| `Friday/Core/RealtimeDictationProvider.swift` | 实现 Dictate 的 Realtime WebSocket 客户端；发送单轮 PCM16 音频并解析最终文本、原始转写和用量。 |
| `Friday/Core/SessionServiceHealthClient.swift` | 调用独立 `/ready` 端点，只有本地服务和 OpenAI 模型路由都就绪时才开放 Live，并解码累计签发与账单可见性。 |

### 3.3 Runtime

| 文件 | 作用与功能 |
| --- | --- |
| `Friday/Runtime/Conversation/ConversationAudioLevels.swift` | 定义音频强度与多段声波的跨层数据契约，避免 Platform 音频实现泄漏到 UI。 |
| `Friday/Runtime/Conversation/ConversationDiagnostics.swift` | 定义 Talk 结构化结束原因和无内容诊断接口，把最近一轮生命周期轨迹写入本地 JSONL。 |
| `Friday/Runtime/Conversation/ConversationRuntime.swift` | 定义 Talk Runtime 描述、Provider/音频端口、音频所有权和原子启停协议，并用 Direct Realtime 包装器保持现有产品路径。 |
| `Friday/Runtime/Conversation/ConversationSessionLedger.swift` | 为单轮 Talk 建立稳定 Session ID，累计无内容的响应数、token 和成本，并只对没有新用户输入的连续响应提供风暴保护。 |
| `Friday/Runtime/Conversation/ConversationTurnCorrelator.swift` | 建立 Turn、Response、Assistant Item 和 Playback 身份映射，隔离迟到或重复的 Realtime 事件。 |
| `Friday/Runtime/Conversation/UserTurnTranscription.swift` | 定义 final user transcript、来源、用量、健康状态和可替换的最终转写 Provider，并提供 Mock/Unavailable 实现。 |
| `Friday/Runtime/Action/ConversationActionBridge.swift` | 把 Realtime 的明确输入框写入工具调用转换为供应商无关 `ActionProposal`，串行调用本地执行器，并按 Tool Call ID 缓存回执以防重复写入。 |
| `Friday/Runtime/Work/ConversationWorkBridge.swift` | 将 Talk 工具调用与同 Turn 最终转写关联，编排草稿确认、正式 Work 提交、查询、取消和终态观察。 |
| `Friday/Runtime/Work/ActionProposal.swift` | 定义 Agent 动作提议、本地执行回执、风险/权限/可撤销性，以及带版本、方法校验和 64KB 上限的 RPC JSON 契约；不执行动作。 |
| `Friday/Runtime/Work/WorkDraft.swift` | 定义正式 Work 前的会话内任务草稿、来源 Turn、最终转写和确认状态。 |

### 3.4 Providers

| 文件 | 作用与功能 |
| --- | --- |

### 3.5 Features

| 文件 | 作用与功能 |
| --- | --- |
| `Friday/Features/ConversationCoordinator.swift` | 编排 Talk 的激活、可替换 Runtime、Action/Work Bridge、连接期输入缓冲、图片上下文、端点超时、异常保护与结束清理；不再分别启动 Provider 和音频。 |
| `Friday/Features/ConversationCoordinatorEvents.swift` | 处理 Talk Provider 事件、Provider 自管播放、本地 Action/后台 Work 工具路由与结果回传，维护用户 Turn 到真实播放的状态转换。 |
| `Friday/Features/ConversationCoordinatorDiagnostics.swift` | 把 Coordinator 状态和身份映射为无内容诊断字段，记录每轮端点、请求、首段音频、播放和工具解析耗时，并统一安全提示。 |
| `Friday/Features/ConversationPresentation.swift` | 将 Talk 运行时状态转换为灵动岛表情、声波和岛内提示，隔离 Coordinator 与具体视图实现。 |
| `Friday/Features/InputOverlay.swift` | 定义不抢焦点且启动后常驻的顶部灵动岛模型、窗口控制器和视图，处理点击展开、外部点击收起，并承载录音、处理、结果与恢复操作。 |
| `Friday/Features/InputOverlayAtmosphere.swift` | 按工作流状态绘制灵动岛的低透明度氛围背景，并适配降低动态效果。 |
| `Friday/Features/IslandWaveform.swift` | 绘制 Dictate 与 Talk 共用的固定尺寸声波、等待动画和对话表情。 |
| `Friday/Features/ScreenRegionSelection.swift` | 在多显示器上提供透明拖拽框选交互，只产出用户选择的全局坐标，不负责截图。 |

### 3.6 Platform

| 文件 | 作用与功能 |
| --- | --- |
| `Friday/Platform/AccessibilityInputService.swift` | 通过 Accessibility 查找并锁定可编辑目标，恢复焦点，使用剪贴板与模拟粘贴写入文本。 |
| `Friday/Platform/FocusedInputActionExecutor.swift` | 只执行可撤销本地文字写入；按显式应用或 Talk 启动目标复验输入框，并把粘贴结果映射为 `succeeded/failed/unknown` 回执。 |
| `Friday/Platform/RunningApplicationResolver.swift` | 从正在运行的常规应用中解析用户说出的名称、Bundle ID 和有限别名；歧义或未运行时明确失败，不启动应用。 |
| `Friday/Platform/ConversationAudioService.swift` | 编排 Talk 的 VoiceProcessingIO 主路径与 AVAudioEngine 半双工降级，管理近场输入门、最长四秒的 Realtime 端点静音交接、播放生命周期和双向音量。 |
| `Friday/Platform/GlobalHotKeyService.swift` | 监听纯 `Fn`、`Control + Option` 和 `Control + Command` 修饰键手势，并避免吞掉普通系统快捷键。 |
| `Friday/Platform/IslandBackdropCaptureService.swift` | 在展开灵动岛期间持续捕获窗口后方区域，排除 Friday 自身并只向本地液态玻璃渲染器提供内存 JPEG 帧。 |
| `Friday/Platform/MicrophoneCaptureService.swift` | 管理麦克风权限、单轮录音引擎、PCM16 音频分片、实时音量和本地语音存在检测。 |
| `Friday/Platform/ScreenRegionCaptureService.swift` | 使用 ScreenCaptureKit 截取明确框选的区域，在内存中完成坐标换算与 JPEG 压缩。 |
| `Friday/Platform/VoiceProcessingAudioUnit.swift` | 直接连接 macOS VoiceProcessingIO 播放与采集总线，在内部 48 kHz 和 Realtime 24 kHz PCM16 之间转换，并提供真实播放回执。 |
| `Friday/Platform/WakeWordService.swift` | 定义可替换的唤醒词协议，并提供本地 Speech 实现和默认不监听的 Mock 实现。 |

## 9. 文件头约定

Swift 和 JavaScript 文件把下面三行放在 import 之前：

```text
// 功能：说明这个文件向系统提供什么能力。
// 职责：说明这个文件管理的关键流程、数据、依赖和主要输出。
// 边界：说明这个文件明确不负责的工作或禁止产生的副作用。
```

Shell 脚本保留解释器声明，并紧接着写文件头：

```sh
#!/bin/zsh
# 功能：说明脚本完成什么检查或操作。
# 职责：说明脚本编排哪些命令、输入和输出。
# 边界：说明脚本不触发哪些外部操作、付费调用或真机行为。
```

注释应描述文件级职责，不逐行复述实现；完整写法和同步触发条件见 `docs/编程Agent规范.md`。
